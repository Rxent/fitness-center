# Пояснительная записка (диплом)

В этой папке лежит пояснительная записка к дипломному проекту и средства
её сборки.

## Файлы

- `diploma.docx` — собранный документ Word. Можно сразу открывать и править.
- `build.py` — скрипт-сборщик. Форматирует документ по методическим
  указаниям ОГБПОУ «Томский техникум информационных технологий».
- `content.py` — текст пояснительной записки по разделам. Править текст
  удобнее всего здесь, а потом пересобрать документ.
- `screenshots/` — скриншоты работающей системы, вставляются в
  Приложение В.

## Оформление

Скрипт сборки применяет следующие параметры по методичке:

- формат листа А4, поля: левое 30 мм, правое 15 мм, верхнее/нижнее 20 мм;
- шрифт PT Astra Serif 14 пт (если в системе нет этого шрифта, Word
  подставит близкий по метрике);
- межстрочный интервал 1,5, абзацный отступ 1,25 см;
- заголовки разделов — прописными, по центру, каждый раздел с новой
  страницы;
- нумерация страниц — снизу по центру, титульный без номера;
- нумерованные списки в формате «1)», последний пункт — с точкой.

## Как пересобрать документ

Из корня проекта:

```bash
python docs/diploma/build.py
```

Скрипт перезапишет `diploma.docx`. Откройте его в Word или LibreOffice и
нажмите F9 на поле «Содержание» — программа пересчитает оглавление с
правильными номерами страниц.

## Что изменить перед защитой

1. В `build.py`, функция `build_title_page` — подставить ФИО студента,
   номер группы, ФИО руководителя и нормоконтролёра.
2. При желании дополнить содержание: можно добавить в `content.py`
   свою аналитику, скриншоты, экономическую часть (если потребует
   комиссия).
3. Проверить список литературы — добавить книги/статьи из вашей
   программы обучения, чтобы избежать вопросов про «чужие источники».

## Структура документа

1. Введение (актуальность, цель, задачи, объект, предмет).
2. Аналитическая часть (предметная область, обзор решений,
   постановка задачи).
3. Проектная часть (выбор технологий, архитектура, БД, ролевая модель).
4. Реализация (структура проекта, модели, ключевые функции, отчёты).
5. Тестирование (ручная проверка основных сценариев).
6. Заключение.
7. Список использованных источников.
8. Приложения А, Б, В (листинги и скриншоты).
